
# Short-Link-URL

A simple, URL shortening service. Quickly transform long, long and complex links into short, complete with basic click tracking.


## Documentation

 - [Architecture (draw.io)](https://drive.google.com/file/d/1PSynrpg7lkRJQhrKeA5O48N9BiudiBUa/view?usp=sharing)
 - [Database Diagram (draw.io)](https://drive.google.com/file/d/1XdRJGBdkIhV9_6-RGprzrb6p_5xWejnX/view?usp=sharing)

## Tech Stack
-   ### Back-End
    - Java 
    - Spring Framework
    - Redis

-  ### Front-End
    - Typescript
    - Angular Framework
    - Bootstrap (UI)

-  ### Cloud Storage
    - Cloudinary

## Features
-   ### Guest
    - Shorten Link
    - QR Code Generator
    - Google OAuth Login
-  ### User
    - Management Their Own Link
    - Link Tracking
    - Secure Password Reset
-  ### Admin
    - Simple Analyze Dashboard
    - Management Link
    - Management User
## Deloyments
-   ### Database
     - PostgreSQL (Render)
-  ### Back-End
     - [Java Spring Dockerization (Render)](https://shortlink-be-yji2.onrender.com/)
     - Redis (Upstash)
-  ### Front-End
   - [Angular (Vercel)](https://shorten-link-url-fe-pzm4.vercel.app/)

- ###  Demo Link Here
   - [Try](https://shorten-link-url-fe-pzm4.vercel.app/)
   - Please note: Since the Backend service is hosted on a Render Free Tier instance, the server is configured to spin down after a period of inactivity.

    -  Upon first access or after a long idle period, the server needs to spin up, which may take around 10-15 minutes. Please be patient; the application will function normally once the server is fully awake.
